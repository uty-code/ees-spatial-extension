# 디자인 일관성 및 UI/UX 고도화 전략 보고서

본 보고서는 사원 평가 시스템(EES)의 시각적 완성도를 극대화하고, 사용자에게 일관된 조작 경험을 제공하기 위한 종합 디자인 가이드라인 및 개선 로드맵입니다.

---

## 1. 정밀 현황 분석 (Gap Analysis)

현재 시스템은 개별 페이지의 완성도는 높으나, 페이지 간 연결성 및 컴포넌트의 파편화가 진행되고 있습니다.

### 1.1 스타일 코드 파편화 (CSS Drift)
- **현상**: `evaluators/list.html`과 `elements/list.html` 내부에 `.premium-card`, `.table-custom` 스타일이 중복 선언되어 있음.
- **리스크**: 디자인 변경 시 누락 가능성이 높으며, 브라우저 렌더링 성능에 부정적 영향을 미침.

### 1.2 컴포넌트 위계 불일치 (Visual Hierarchy)
- **액션 버튼(Action Buttons)**: 
    - 평가자 관리: Glassmorphism 기반의 고성능 `btn-glass` 스타일 적용.
    - 평가 요소/차수 관리: Bootstrap 기본 `btn-outline-*` 스타일 혼재.
- **데이터 테이블(Tables)**: 테이블 행(Row)의 패딩, 텍스트 크기, 마우스 호버 효과가 페이지마다 미세하게 다름 (약 2~4px의 오차).
- **입력 폼(Forms)**: `form-control-custom` 클래스가 일부에만 적용되어, 특정 페이지에서는 기본 흰색 배경의 인풋이 노출되어 다크 테마의 몰입감을 해침.

### 1.3 인터랙션 불일치 (UX Inconsistency)
- **로딩 피드백**: '평가자 관리'에는 버튼 내 스피너가 작동하나, '평가 요소 관리'에서는 전체 페이지 로딩바(`htmx-indicator`)만 작동함.
- **성공/실패 알림**: Alert 배너의 위치와 소멸 애니메이션이 페이지마다 달라 사용자의 인지 부하 유발.

---

## 2. 표준 디자인 시스템 가이드라인 (Design System Standards)

### 2.1 시각적 요소의 자산화 (Visual Assets)
- **배경 및 질감**: 
    - 카드: `rgba(30, 32, 40, 0.6)` 배경 + `blur(10px)` + `border-white (0.1)`.
    - 강조: `linear-gradient(90deg, #6366f1, #a855f7)` (Indigo to Purple).
- **상태 정의 컬러**:
    - **성과**: `Blue (#0d6efd)` - 전문성, 신뢰.
    - **역량**: `Green (#198754)` - 성장, 가능성.
    - **다면**: `Amber (#f59e0b)` - 소통, 조화.

### 2.2 컴포넌트 재사용 전략 (Thymeleaf Fragments)
- **Action Bar**: Glassmorphism 스타일의 버튼 그룹을 전사 공통 프래그먼트로 추출하여 재사용.
- **Status Badge**: 평가 유형별 배지를 전역 스타일(`design-system.css`)로 고정하여 동일한 의미에는 항상 동일한 색상 매핑.

---

## 3. 개선 실행 로드맵 (Action Plan)

### [Phase 1] 디자인 자산 중앙 집중화 (Immediate)
- **파일 통합**: 모든 HTML의 `<style>` 블록을 `static/css/design-system.css`로 통합.
- **토큰화**: 매직 넘버(픽셀값 등)를 CSS 변수(`--ees-card-blur`, `--ees-primary-color`)로 교체.

### [Phase 2] 관리자 경험(Admin UX) 동기화 (Short-term)
- **UI 이식**: '평가자 관리'의 고도화된 UI(버튼 그룹, 로딩 스피너)를 '평가 요소 관리', '평가 차수 관리'에 수평 전개.
- **테이블 표준화**: 모든 데이터 그리드에 동일한 `.table-ees` 클래스 적용.

### [Phase 3] 마이크로 인터랙션 강화 (Mid-term)
- **HTMX 연동**: 모든 비동기 요청 시 버튼 내 로딩 상태와 상단 프로그래스 바가 동시에 작동하도록 스크립트 표준화.
- **성찰적 알림**: Toast UI를 도입하여 작업 결과 피드백을 화면 우측 하단에 일관되게 배치.

---

## 4. 기대 효과 (Expected Impact)

1. **브랜드 전문성 강화**: "깔끔하게 정리된 느낌"을 주어 포트폴리오 면접 시 시각적 완성도에서 압도적인 가점 획득.
2. **유지보수 효율성**: 디자인 변경 요구 시 단 하나의 CSS 파일만 수정하여 전사 적용 가능.
3. **사용자 신뢰도**: 일관된 인터랙션을 통해 시스템에 대한 사용자의 신뢰와 숙련도 향상.

---
> [!IMPORTANT]
> **디자인 일관성은 단순한 심미성을 넘어 시스템의 '완성도'를 증명하는 지표입니다.**
